Electrocardiogram heartbeat classification project (GitHub note)

Summary

Proyecto breve: clasificación de latidos en un segmento de señal de electrocardiograma según tipo de arritmia. El enfoque reportado en el README consiste en un perceptrón multicapa (MLP) entrenado con backpropagation; para reducción de dimensionalidad se mencionan PCA y SOM.

Key points

- Task: ECG heartbeat classification by arrhythmia type.
- Model: Multilayer perceptron (MLP) with backpropagation.
- Dimensionality reduction: PCA (Principal Component Analysis) and SOM (Self-Organizing Map).
