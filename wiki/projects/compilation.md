Mini-C -> x86-64 compiler (course project)

A compilator was created to generate x86-64 assembler code from a C fragment called "mini-C". According to the raw note, mini-C is a 100% C-compatible fragment, meaning any Mini C program is also a valid C program.

This work is recorded as part of the École Polytechnique course INF564 : Compilation (see course page linked in the raw source). For the École Polytechnique transcript and related records, see [[education/ecole-polytechnique-transcript-2016-2017.md]].

Source / raw note: [[sources/raw-github-compilation.md]]

Summary

- Goal: compile a restricted C fragment (mini-C) to x86-64 assembly.
- Key claim: mini-C is fully compatible with C (every mini-C program is also a C program).
- Context: course INF564 (Compilation) at École Polytechnique.
