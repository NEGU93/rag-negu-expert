This page captures the raw GitHub / documentation README for the Python library "upsetplot" (UpSetPlot), an implementation of UpSet plots (Lex et al., 2014) for visualising set overlaps.

High-level summary

- Project: upsetplot — Python library to create UpSet plots (an alternative to Venn diagrams for set intersections).
- Primary purpose: visualize set overlaps and distributions of variables across set intersections; supports horizontal and vertical orientations and distribution/aggregation plots when given a DataFrame.
- Documentation: https://upsetplot.readthedocs.io (referenced in raw).
- Upstream repository (inferred from badges): https://github.com/jnothman/UpSetPlot
- License (badge indicated): BSD-3-Clause (badge |licence| in raw).

Contents present in raw (not exhaustive)

- Description of internal data format: a pandas.Series indexed by boolean membership combinations (each index level corresponds to a named category) representing counts per subset.
- Example helper functions shown/mentioned: generate_counts, plot, from_memberships, from_contents, from_indicators.
- Usage examples (doctest-style) demonstrating construction of example counts, plotting via matplotlib, and saving outputs with pyplot.savefig.
- Plot styles: horizontal (default) and vertical; examples and image references included in docs.
- Distribution plots: when input is a DataFrame, upsetplot can plot distributions of variables within each subset (example: diabetes dataset example referenced).
- Installation instructions: pip install upsetplot
- Dependencies noted: pandas, matplotlib >= 2.0, seaborn (required for UpSet.add_catplot)
- Comparison/justification: author commentary on why this implementation was created as an alternative to py-upset (maintenance, input format, features).
- References: Lex et al. (2014) "UpSet: Visualization of Intersecting Sets" (DOI: https://doi.org/10.1109/TVCG.2014.2346248).
